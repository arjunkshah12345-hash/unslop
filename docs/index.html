Five passes, in order

Spacing first, because it is structural and hard to see once colour changes. Data last, because it depends on every type and colour decision before it.

01

Spacing: measure, then snap

Guessed spacing is almost consistent. Nobody sees 3px; everybody feels it.

  • Measure rendered gaps, not the CSS you think applies.
  • Every value from one scale: 4, 8, 12, 16, 24, 32, 48.
  • Repeated siblings sit at identical gaps. Use gap, not margins.
  • At most four corner radii.

02

Surfaces: calm the colour

When everything glows, nothing is important.

  • One neutral ramp and one accent, for the one primary action.
  • No gradient chrome, no gradient text, no glow.
  • Status colours only mean status.
  • Muted text still clears 4.5:1.

03

Icons: real icons, not emoji

Emoji change per platform, ignore your colours and read as a toy.

  • No emoji in nav, labels, buttons or status.
  • One icon set, one 1.5px stroke, currentColor.
  • Status is a dot plus a word.
  • Delete icons that repeat their label.

04

Type: honest type

Slop copy performs excitement. Honest type says what the thing is.

  • Names, not hype. No exclamation marks.
  • Sentence case, two or three weights, at most eight sizes.
  • Numbers get precision, units, context and tabular figures.
  • Monospace for hashes, branches and IDs.

05

Data: data that reads

A spinning five-slice donut looks like data and says nothing.

  • Chart the question: trend, history, or part of a whole.
  • Animate in once, then hold still.
  • Every number gets a range, a comparison or a target.
  • Label directly; legends only when labels collide.

The audit

One read-only script finds the measurable tells: off-grid spacing, uneven siblings, emoji, glow, gradient text, hype copy, failing contrast, looping charts. The skill runs it before the first pass and after every pass.

  1. From Node

    Loads the page in headless Chromium and exits 1 while errors remain, so it can gate CI.

  2. From any agent

    Evaluate audit.js with whatever browser tool the agent has. The result is the report.

  3. From DevTools

    Paste the file into the console for a table of every issue.

  4. On this page

    This site was built with the skill. Check it yourself.

Install

A plain folder: SKILL.md, the rulebook, the audit and the demo. It works with Claude Code and any agent that reads skills.

Skills CLI

Installs into every agent it finds.

npx skills add arjunkshah12345-hash/unslop

Claude Code

Clone it and link the folder.

git clone https://github.com/arjunkshah12345-hash/unslop
ln -s "$PWD/unslop/skills/unslop" ~/.claude/skills/unslop

Any other agent

Copy skills/unslop to wherever it loads skills, or point it at SKILL.md.

cp -r unslop/skills/unslop ~/.agents/skills/

Then ask: unslop this dashboard
